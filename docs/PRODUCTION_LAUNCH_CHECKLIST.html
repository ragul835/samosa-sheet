3. Launch task 1 — domain and DNS

  1. Purchase or confirm the final domain, for example yourdomain.in.
  2. Connect it to the selected static host and follow the host’s DNS instructions.
  3. Enable HTTPS. The browser must show a valid certificate without warnings.
  4. Redirect HTTP to HTTPS and decide whether the canonical address uses www or no www.
  5. Set NEXT_PUBLIC_SITE_URL to the canonical HTTPS origin without a trailing slash.
NEXT_PUBLIC_SITE_URL="https://your-real-domain.in"

Acceptance criteria

  • HTTPS homepage loads publicly
  • HTTP redirects to HTTPS
  • Only one canonical domain version is used
  • No certificate errors

11. Automatic email + WhatsApp setup

The production design uses a Cloudflare Worker and Queue with Resend. The website durably queues the enquiry, opens WhatsApp immediately with the prepared message, and sends the email notification asynchronously with automatic retries.

What you need

  • Cloudflare account
  • Resend account
  • Verified sending domain
  • Public website domain
  • Access to DNS records

Resend

  1. Add the real domain in Resend.
  2. Add the DNS records Resend provides.
  3. Wait until verification succeeds.
  4. Create a restricted API key.
  5. Choose a sender such as enquiries@your-real-domain.in.

Worker configuration

Edit worker/wrangler.toml:

ALLOWED_ORIGIN = "https://your-real-domain.in"
FROM_EMAIL = "Samosa Sheet Website <enquiries@your-real-domain.in>"
TO_EMAIL = "orders@samosasheet.com"

Store and deploy from the project:

cd /home/dell/SS/samosa-sheet-website/worker
npx wrangler login
npx wrangler secret put RESEND_API_KEY
npx wrangler deploy
Never place the Resend API key in .env.local under a NEXT_PUBLIC_ name, source code, Git, screenshots or chat.

Connect the website

NEXT_PUBLIC_ENQUIRY_API_URL="https://api.samosasheet.com/"

Rebuild the website after setting this variable. Without it, the interface intentionally remains in WhatsApp-only mode.
